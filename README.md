# ДомМаркет — Сеть магазинов товаров для дома

Учебный проект — сайт сети розничных магазинов товаров для дома, разработанный в рамках производственной (эксплуатационной) практики.

**Студент:** Серебренников Дмитрий Валерьевич
**Направление:** 38.03.05 Бизнес-информатика, Цифровая экономика
**Срок практики:** 03.11.2025 — 28.12.2025
**Руководитель практики от Университета:** Королькова М.Н.

## Стек

- HTML5 + CSS3 + чистый JavaScript (без CMS, без фреймворков)
- Хранилище: `localStorage` (имитация серверной БД)
- Хостинг: GitHub Pages
- 100% статический сайт

## Структура

```
Сайт на ПК/
├── index.html       — главная страница
├── catalog.html     — каталог товаров (43 товара, фильтры, поиск)
├── news.html        — новости и акции (6 статей)
├── stores.html      — магазины сети (7 городов)
├── about.html       — о компании
├── contacts.html    — контакты + форма обратной связи
├── account.html     — личный кабинет (вход, регистрация, чат)
├── sitemap.html     — карта сайта
├── 404.html         — страница ошибки
├── css/
│   ├── style.css      — стандартный стиль (тёплая бежево-зелёная палитра)
│   └── accessible.css — версия для слабовидящих по ГОСТ Р 52872-2012
├── js/
│   ├── data.js     — данные каталога, новости, магазины, пользователи
│   ├── app.js      — общая логика, шапка, футер, темы
│   ├── auth.js     — регистрация и вход
│   ├── messages.js — обмен сообщениями клиент ↔ менеджер
│   └── catalog.js  — фильтрация и поиск каталога
└── screenshots/    — скриншоты для отчёта
```

## Возможности

- ✅ 7 контентных страниц (5–10 по требованию задания) + карта сайта + 404
- ✅ Каталог с поиском по тексту, фильтрами по категориям и цене
- ✅ Лента новостей (6 публикаций) с фильтрацией по месяцам
- ✅ Форма обратной связи (попадает в общую очередь сообщений)
- ✅ Обмен сообщениями клиент ↔ администратор (двусторонний чат)
- ✅ Регистрация клиентов (саморегистрация)
- ✅ Создание учётных записей администратором с выбором роли
- ✅ Три уровня доступа: администратор, менеджер, клиент
- ✅ Переключатель «Версия для слабовидящих» (ГОСТ Р 52872-2012):
   - чёрный фон, жёлтый текст
   - крупный шрифт (≥ 20 px)
   - подчёркнутые ссылки
   - повышенный контраст (≥ 4.5:1)
- ✅ Адаптивная вёрстка (мобильная + планшет + десктоп)

## Запуск локально

```bash
# из папки "Сайт на ПК"
python -m http.server 8000
# затем открыть http://127.0.0.1:8000/
```

Или через XAMPP — просто положить папку в `C:\xampp\htdocs\` и открыть `http://localhost/Сайт на ПК/`.
